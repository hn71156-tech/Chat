# Mô tả dự án để đưa vào CV / GitHub

## Tên dự án
Vietnamese Customer Review Sentiment Analysis

## Mô tả CV (chỉ sử dụng sau khi bạn đã tự chạy và hiểu mã)
- Xây dựng ứng dụng NLP phân loại đánh giá tiếng Việt thành positive/negative/neutral bằng Python, scikit-learn, TF-IDF và Logistic Regression.
- Tạo pipeline huấn luyện và đánh giá với train/test split, Accuracy, Precision, Recall, F1-score và confusion matrix.
- Xây dựng giao diện demo bằng Streamlit, lưu/tải mô hình bằng joblib.

**Không ghi số liệu hiệu năng cụ thể** cho đến khi bạn chạy thí nghiệm trên dataset phù hợp và lưu được kết quả kiểm chứng.

## Mô tả GitHub
Ứng dụng demo phân tích cảm xúc đánh giá tiếng Việt. Có mã huấn luyện, giao diện Streamlit, dữ liệu mẫu tự biên soạn và tài liệu giải thích pipeline ML. Dữ liệu mẫu chỉ phục vụ minh họa, không đại diện dữ liệu thực tế.
